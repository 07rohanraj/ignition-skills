# Perspective Embedded View Components (Shared)

This skill covers the embedded view components. Each has its own file in this folder. **Read the specific component file below for the authoritative schema before generating any Perspective JSON.**

## Components

| Component | File | When to Use |
|---|---|---|
| Embedded View | `Perspective Embedded View Component.md` | Including a sub-view inside another view |
| Flex Repeater | `Perspective Flex Repeater Component.md` | Repeating a template view per data row |

## Instructions

1. Identify which embedded component you need from the table above.
